# Ananas
Ananas is an implementation of a custom lisp dialect. **NOTE**: the project is unfinished,
so expect bugs, inconveneinces, and lack of features.

## Quick start
Prerequisites:
+ An x86_64 machine running either Windows or Linux
+ A C compiler

Building:
```shell
# On Windows: build.bat
./build.sh
# On windows: .\ananas.exe
./ananas
```
